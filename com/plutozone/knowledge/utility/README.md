# com.plutozone.knowledge.utility

## PC 최적화
- 시작
	- 시작 프로그램 at 작업 관리자
	- 검색, 뉴스 및 관심사 등 at 작업 표시줄
- 실행
	- 1st: 크롬 등 at 작업 표시줄
	- 2nd: 프로그램 목록 by Classic(Open)-shell
- 디스크
	- 디스크 정리 + 시스템 파일 정리 at 디스크 속성
	- WinDirStat
- 레지스트리
	- 모든 파일, 가장 큰 파일 by Wise Registry Cleaner
