## Usages
### Emmet
- 설정(Settings) > 확장(Extensions) > Mmmet
- "Trigger Expansion On Tab" 활성화
- *.html 파일 생성
- 유용한 단축 기능(HTML 파일에서 단축어를 입력한 다음 `Tab` 키)
	| 단축어 | 결과 | 설명 |
	| :--- | :--- | :--- |
	| `!` | HTML5 기본 문서 구조 | HTML 기본 템플릿 생성 |
	| `html:5` | HTML5 기본 문서 구조 | HTML 기본 템플릿 생성 |
	| `div` | `<div></div>` | div 요소 생성 |
	| `div.container` | `<div class="container"></div>` | class가 container인 div 생성 |
	| `div#header` | `<div id="header"></div>` | id가 header인 div 생성 |
	| `p` | `<p></p>` | 문단 요소 생성 |
	| `p*3` | `<p></p>` 3개 | 문단 요소 3개 생성 |
	| `ul>li` | `<ul><li></li></ul>` | ul 안에 li 생성 |
	| `ul>li*3` | li 요소 3개가 포함된 ul | 목록 항목 3개 생성 |
	| `div>p` | `<div><p></p></div>` | div 안에 p 생성 |
	| `div+p` | `<div></div><p></p>` | div와 p를 형제 요소로 생성 |
	| `nav>ul>li*3>a` | 중첩된 메뉴 구조 | 내비게이션 메뉴 생성 |
	| `input:text` | `<input type="text" name="" id="">` | 텍스트 입력 필드 생성 |
	| `a` | `<a href=""></a>` | 링크 요소 생성 |
	| `img` | `<img src="" alt="">` | 이미지 요소 생성 |
	| `table>tr*3>td*2` | 3행 2열 테이블 구조 | 표의 행과 셀 생성 |
